Install

Copy a pattern into your app, with the components and helpers it uses. Its stylesheet goes into harmo.css, which you import once. 

npx harmo-ui add sign-in-form

How the forms answer

Each React form takes action, as React 19's <form> does: a function that gets the form's FormData and returns an answer. Give it a server action, such as Next.js's with "use server", and the form works without JavaScript too. In HTML, your own script sends the form, and shows the answer the same way.

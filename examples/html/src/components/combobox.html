With data-multiple on .hcombobox, each choice is a Tag, with a remove button, in a Tag List before the text, and the list stays open while you choose: a pick adds an option, or takes it away, and the text empties for the next one. Backspace in an empty field takes the last choice away, and ← moves to the remove buttons. A form sends each choice. Required, the field is valid while there's a choice, so its input is required only while there's none, and aria-required says so throughout.

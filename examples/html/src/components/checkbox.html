Unchecked, checked, and mixed, each in a horizontal Field with its label. Mixed is the indeterminate DOM property, which has no HTML attribute: a script sets it, so it doesn't show in the markup.
disabled dims the checkbox in any state, and its label turns gray.
--harmo-checkbox-size resizes the box, and the marks scale with it; here 24px instead of 20px.
.hfield-content holds the label and a description, connected to the checkbox with aria-describedby.

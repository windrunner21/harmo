Type @ and a few letters: the people whose name or handle has them are listed, the first highlighted. The arrow keys move through them, Enter or Tab puts the handle in the note, and Escape closes the list. Focus stays in the field, and the handle is highlighted in the text.

In an Input, for a line such as a task's title. With its trigger typed, ↓ or ↑ opens the list again after Escape closed it, as there are no lines for them to move between.

With the trigger at the start only, such as / for a chat's commands, a slash anywhere else is just a slash. Its list opens over the field first, as for a composer at the bottom of a chat.
  • /summarize Summarize this ticket
  • /draft Draft a reply
  • /translate Translate the customer's message
A message box with a list for each trigger: @ for people, # for channels, and / at the start for a command. The trigger nearest the caret picks the list. Each mention of someone or something in a list is highlighted as you type, as in the text it starts with, and stays a plain text field underneath.

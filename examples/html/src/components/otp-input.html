One Input holds the whole code, with a slot drawn for each digit over it, so typing, pasting, undoing, and a phone filling the code in from a message all work as in any field. Press a slot to type over its digit. Without its script, it's a plain Input, which a form still sends.
Four slots, with maxlength and pattern to match. In React, it's length={4}, from 4 to 12.
A dash between the slots splits the code in groups, here 3 and 3, as its message might write it. The value has no dash, and a pasted 123-456 loses it. In React, it's groups.
data-characters="alphanumeric", in React characters="alphanumeric", takes letters too, shown and sent in capitals, in the monospaced font, whose 0 and O differ. Here 8 of them, in groups of 4.
The Field's description can say how many digits to type, and its error turns every slot red, as aria-invalid does an Input's border.

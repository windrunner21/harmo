A field filled in gray, with a magnifier at its start, such as above a list of conversations. Name it with aria-label where there's no label to see. Once there's text, the clear button empties it; Escape does too, so the button stays out of the Tab order.
Leave the clear button out where a field this short doesn't need it. Escape still empties it.
In a Field, its label names it, as for any Input.
Typing narrows the list as you go; clearing, by the button or Escape, brings every row back. Each tells the app the field's new value, as typing does, so the app's filter follows. The rows are ghost Cards.

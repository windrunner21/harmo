React playground

Composable UI building blocks

Install them, adapt them, or copy them into your project. Familiar to use, polished by default.

Pick a component to see every variation of it. Each example is the HTML playground's, built with Harmo's React components: rendered on the server, then hydrated in the browser. Open its code to copy it.

Patterns are whole tasks built from the components, such as signing in or contacting support, each with what to type in its examples and what your app needs.
